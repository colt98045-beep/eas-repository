# Contributing to EAS Repository

Thanks for your interest in the project.

## Running locally

```bash
git clone https://github.com/colt98045-beep/eas-repository.git
cd eas-repository
python eas_monitor.py
```

Then open http://localhost:8080 in your browser.

## Reporting issues

Please open a GitHub Issue and include:
- What you expected
- What happened
- Steps to reproduce
- Python version and OS

## Pull requests

1. Fork the repository
2. Create a branch for your change
3. Make your changes (keep the style consistent with the existing code)
4. Test that the server starts and the dashboard loads
5. Open a pull request with a clear description
